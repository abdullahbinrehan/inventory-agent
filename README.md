# 📦 AI Inventory Agent

An automated, multi-tenant inventory monitoring and chatbot agent for e-commerce stores.

### Features
- **Dynamic Credentials:** Users can log in and connect their own Shopify, Gmail, and Discord accounts securely via Supabase.
- **AI Alerts:** Runs inventory analysis and sends HTML emails and rich Discord embeds.
- **RAG Chatbot:** Ask questions about current inventory and historical data using Groq and ChromaDB.
- **Premium UI:** Deep dark mode interface with Plotly charts and iMessage-style chat bubbles.
